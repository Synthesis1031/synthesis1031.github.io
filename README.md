# Synthesis

Website for the short film *Synthesis*, hosted on GitHub Pages.

## Structure

```
index.html              Main page
css/                    Stylesheets
js/                     Scripts
assets/
  images/
    concept-art/
      characters/       Character designs
      environments/     Locations and sets
      props/            Objects and props
    storyboards/        Storyboard panels
    stills/             Frames from the film
    posters/            Posters and key art
    ui/                 Logos, icons, site graphics
  audio/
    music/              Score and soundtrack
    sfx/                Sound effects
    voice/              Dialogue and voiceover
  video/
    trailers/           Trailers and teasers
    clips/              Short clips and behind-the-scenes
  fonts/                Custom web fonts
```

## Notes

- Export web-ready versions of files (JPG/WebP for images, MP3/OGG for audio, MP4 for video). Keep layered source files (PSD, Procreate, etc.) out of the repo.
- GitHub blocks files over 100 MB and Pages sites should stay under 1 GB, so host full-length video on YouTube/Vimeo and embed it.
- Use lowercase, hyphenated file names (e.g. `hero-sketch-v2.jpg`).
